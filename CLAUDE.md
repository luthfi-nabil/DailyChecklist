## Daily Checklist

The cross-platform apps with sync feature that allows user to log their activities and track their progress in daily basis. 

## Rules

- Apps in Desktop (Electron) + Mobile (Flutter)
- Implement design pattern best practice for both of the apps
- Only user can commit the code
- Any Milestones planning add in "Milestone.md" file
- If there is ambiguous or not clear instruction, freely to ask
- Design use .html mockup format
- Use local SQLite database for local data persistence on both Desktop and Mobile
- Sync API must support auto-detection on the local network (e.g., mDNS/UDP discovery) so users do not need to manually configure an IP address
- Desktop app must provide an option to run on startup in the background (system tray) for automatic sync with Mobile
